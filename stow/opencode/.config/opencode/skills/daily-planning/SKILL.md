# Daily planning

First load the `planner` skill (which itself loads `notetaking`).

This is a **guided, procedural** skill: walk through each step below in
order, one at a time, discussing it with the user rather than just listing
the steps and moving on. Wait for their response before advancing. If they
want to skip a step, skip it and move to the next — the full sequence is
preferred, not mandatory.

Write the outcome of this session as a new dated entry under the Journal
section of `planner.org` (most recent at the top), using the same
"Daily check-in" sub-heading structure as existing entries in that file,
per the `planner` skill's conventions.

## The steps, in order

1. **Review daily habits** — look at the Daily section's habit TODOs;
   note anything already done or clearly not going to happen today.
2. **Work: intention** — what's the intention for work today?
3. **Fitness: intention**
4. **Learn: intention**
5. **Art: intention**
6. **Self-care: intention**
7. **Respect my spaces: intention**
8. **Acknowledge stressors verbally** — ask what's currently weighing on
   them; let them talk through it, don't rush this step.
9. **Constructive: action or acceptance?** — for the stressor(s) just
   named, work through with them whether it calls for an action or for
   acceptance. This step and step 8 together are the maladaptive-thought
   work — help them step back from an unhelpful framing of the thought,
   rather than just accepting the first framing at face value.
10. **Meditation: gratitude** — ask for one or more things they're
    grateful for right now.
11. **Meditation: self-affirmation**
12. **Meditation: presence, rate able-bodiedness**
13. **Review calendar** — pull up the relevant scheduled items from
    `planner.org` (Daily/Weekly/Monthly sections, and anything dated) for
    today.
14. **Review work checklist** — scan for incomplete/carried-over TODOs
    from previous days (open TODOs with past `SCHEDULED`/`DEADLINE` dates)
    and help decide which to tackle today.
15. **Notes** — anything else they want to capture before wrapping up.

## What this skill is not

Not a substitute for `checkin` (lightweight, anytime updates) or `review`
(retrospective on work already done) — this is specifically the guided
morning-shaped procedure above, even if actually run at a different time.
